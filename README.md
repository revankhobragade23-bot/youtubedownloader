# YouTube Downloader using Python 🎥

A simple YouTube video downloader built with Python using the `yt-dlp` library.

I made this project while learning how Python libraries can be used to automate tasks and work with online media.

## 🚀 Features

- Download videos from a YouTube URL
- Downloads video and audio
- Automatically merges video and audio using FFmpeg
- Simple command-line interface
- Beginner-friendly Python project

## 🛠️ Technologies Used

- Python
- yt-dlp
- FFmpeg
